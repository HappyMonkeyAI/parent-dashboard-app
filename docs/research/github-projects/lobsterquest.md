## What it does

Gamified daily routine tracker for a specific 8-year-old with ADHD/Autism. Turns morning tasks into comic-book missions — earn XP, fill a Hero Power bar, unlock screen time after completing all quests.

## Why it matters to us

The most ND-informed design philosophy found in any project. Not code-reusable, but the design thinking is directly applicable. Built by a parent for their ND child — same motivation as Parent Portal.

## Cherry-pick (design insights, not code)

- "How do you make a sock feel as important as a sword?" — visual, immediate, child-owned
- XP instead of ticks: "A tick says done. XP says you grew." Hero Power bar gives accumulation/progress feeling
- Locked reward mechanism: screen time is deferred and earned, not reduced. "The app decides, not the parent" — removes the argument
- Minimal text, maximum emoji — every task card leads with large emoji + short bold name
- Tablet-first, touch-first — large tap targets, no hover states
- No login friction — open and go
- README's "What I'd Build Next" list maps directly to Parent Portal features

## Avoid / Gaps

- Single HTML file with localStorage — no backend, no parent dashboard
- No code to reuse (no license)
- Designed for an 8-year-old; Parent Portal targets a 13-year-old (needs more mature aesthetic)
- Gamification approach (XP, rewards) may create anxiety for some ND users — adapt carefully

## Notes

The README is worth reading in full for its ND design philosophy. Key quote: the app removes the parent-child negotiation by making the system the authority, not the parent.
