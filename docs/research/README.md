# Research

External references, comparisons, and notes gathered during scoping and development.

**This is reference material, not the source of truth.** CONTEXT.md and DESIGN.md govern decisions.

## Structure

- `LINKS.md` — curated links for quick reference
- `templates/project-note.md` — template for project reference notes
- `github-projects/` — one file per referenced GitHub repo
- `notes/` — deeper research writeups (ND design, safeguarding, tech comparisons)

## Rules

- Record URL, license, stack, why it matters, and what to cherry-pick or avoid
- Do not copy code blindly — capture patterns and decisions
- Keep notes concise; prefer short observations over full writeups
- Update LINKS.md when adding new references
